# Змійка

Невелика навчальна гра на HTML, CSS та JavaScript.

## Запуск
Відкрий файл `index.html` у браузері.

## Керування
- WASD або клавіші зі стрілками — рух змійки.
- Кнопка «Почати заново» — перезапуск гри.

## Використані теми
- Об'єкти `character` та `enemy`.
- Спільна функція `drawEntity`.
- Контекст `this`: під час `character.draw()` this посилається на character, а під час `enemy.draw()` — на enemy.
- Обробка події клавіатури та оновлення ігрового поля.
